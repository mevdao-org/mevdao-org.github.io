# MEV DAO field notes

Source for https://mevdao-org.github.io, short practical notes from [MEV DAO](https://mevdao.org) on sweeper bots, EIP-7702 delegations and Flashbots bundles.

Each note is a plain Markdown file in the repo root, built by GitHub Pages with the default Jekyll theme. Corrections and issues are welcome.
